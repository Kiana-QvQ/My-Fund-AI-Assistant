# 交易日规则说明

> 用途：明确「哪一天算交易日」以及四只标的（短债 `012773`、沪深300 `460300`、中证500 `160119`、纳指100 `016452`）每天定投时**哪一天会真正扣款**。
>
> 代码：`scripts/a_share_holidays.py`（离线规则表）、`scripts/trading_calendar.py`（联网交易日历）。

## 一、结论速查

| 问题 | 结论 |
|---|---|
| 定投扣款按哪套日历？ | **A 股交易日**（四只都是场外基金，按基金「开放日」口径） |
| 周末扣款吗？ | 不扣。定投扣款日逢非交易日**顺延至下一交易日** |
| 法定节假日扣款吗？ | 不扣，同样顺延 |
| 交易日 15:00 前后有区别吗？ | 有。15:00 前提交按**当日**净值确认；15:00 后顺延到下一开放日 |
| 纳指100（QDII）不同在哪？ | **扣款日**仍按 A 股交易日；**确认净值**取决于境外市场估值日，境外休市可能再顺延。两者不能混为一谈 |
| 系统怎么判断？ | AKShare 新浪交易日历 → 离线官方休市表 → 都没有就**跳过该日**（fail-closed） |

## 二、A 股交易日规则（权威口径）

**定义**：A 股交易日 = 每周一至周五，**剔除**国家法定节假日及交易所公告的休市日。

上交所 / 深交所 / 北交所每年 12 月发布下一年度的《部分节假日休市安排》，这就是权威口径。国务院的放假安排决定「哪天放」，交易所公告决定「哪天不开市」，两者在调休上班的周末上可能出现差异——**以交易所公告为准**。

**2026 年休市安排**（沪深北交易所 2025-12-22 公告）：

| 节日 | 休市区间 | 恢复开市 |
|---|---|---|
| 元旦 | 2026-01-01（四）～ 01-03（六） | 01-05（一） |
| 春节 | 2026-02-15（日）～ 02-23（一） | 02-24（二） |
| 清明节 | 2026-04-04（六）～ 04-06（一） | 04-07（二） |
| 劳动节 | 2026-05-01（五）～ 05-05（二） | 05-06（三） |
| 端午节 | 2026-06-19（五）～ 06-21（日） | 06-22（一） |
| 中秋节 | 2026-09-25（五）～ 09-27（日） | 09-28（一） |
| 国庆节 | 2026-10-01（四）～ 10-07（三） | 10-08（四） |

额外休市的周末（本来就不开市）：2026-01-04（日）、02-14（六）、02-28（六）、05-09（六）、09-20（日）、10-10（六）。

2026 年三个交易所的休市区间合计 **33 天**，其中 **14 天**本就落在周末（本来就不开市），另有 **19 个工作日**因节假日休市。2026 年共 261 个工作日（365 − 104 个周末日），减去这 19 天，**可开市交易日为 242 天**。

## 三、场外基金扣款与申购规则

1. **开放日 = 定投扣款日**：公募基金（尤其是场外 A 类份额）的开放日通常等同 A 股交易日。
2. **非交易日顺延**：定投扣款日若逢周末或法定节假日，**顺延至下一个开放日**扣款，不会提前、也不会漏扣。
3. **15:00 截止**：每个开放日 15:00 前提交的申购按**当日**净值确认；15:00 后提交顺延到下一开放日。
4. **按日定投的含义**：银行 / 基金公司的「按日定投」= **每个交易日起发起一次扣款**，即「周一至周五的每个交易日」，不是自然日。
   —— 参考 [博时基金直销定投业务规则](https://www.bosera.com/article/detail.do?articleId=10139)：「按日定投：系统会在周一至周五的每个交易日发起定投扣款。」
5. **限额与门槛**：能否扣款还取决于基金 **开放申购 / 限大额**、金额 **≤ 日限额** 且 **≥ 购买起点**。

## 四、QDII 的特殊性（纳指100 `016452`）

QDII 基金有两套时间表，**不要混为一谈**：

| 环节 | 依据 | 说明 |
|---|---|---|
| 申购申请（扣款） | **A 股交易日 15:00** | 与普通场外基金一致 |
| 估值 / 确认净值 | **境外市场估值日** | 纳斯达克开市日；美股假日可能暂停申购或顺延估值 |

因此：

- 系统把「交易日」统一按 A 股日历判断 —— 这与招行 App 的扣款日一致。
- 但**确认净值可能晚于扣款日**，属于正常现象（T+1 / T+2）。
- 若境外市场长期休市，基金公司可能公告**暂停申购**，此时扣款会被拒绝或顺延；系统会在申购状态里体现。

## 五、代码里的判断优先级

`scripts/sync_personal_dca.py::default_is_trading_day` 与 `scripts/trading_calendar.py::is_trading_day_for` 共用同一套优先级：

1. **AKShare 交易日历**：`ak.tool_trade_date_hist_sina()`（新浪财经，含交易所临时调整），并校验返回样本 ≥ 1000 天，防止接口异常被当成「休市」。
2. **离线官方休市表**：`scripts/a_share_holidays.py::A_SHARE_HOLIDAY_RANGES`。适用于依赖缺失、网络不可用、或需要确定性判断的场景（测试也用它）。
3. **两者都无法回答**：该日按**非交易日跳过**（fail-closed）。

```powershell
# 查某天是不是交易日（离线，无需网络）
python scripts/a_share_holidays.py --date 2026-10-15
python scripts/a_share_holidays.py --date 2026-10-01 --market qdii_us

# 联网日历（含交易所临时调整）
python scripts/trading_calendar.py --date 2026-10-15
```

### 为什么 fail-closed 不会丢单

`sync_personal_dca` 每次运行都从「上一笔已记流水之后**逐日重算**到 `--as-of`」。所以某天因为日历不可用被跳过，**下一次运行还会重新判断那一天**，不会永久丢失。这也是为什么它敢在不确定时选择「不记」而不是「按周一至周五记」：多记一笔假流水比漏记一笔更难发现。

> 旧版本在日历不可用时回退到「周一至周五」，会把国庆、春节当成交易日。已改为使用官方休市表。

## 六、2026 年扣款日示例（四只标的）

| 日期 | 星期 | 是否扣款 | 原因 |
|---|---|---|---|
| 2026-09-30 | 三 | ✅ | 节前最后交易日 |
| 2026-10-01 ～ 10-07 | — | ❌ | 国庆休市，顺延 |
| 2026-10-08 | 四 | ✅ | 节后首个交易日，恢复扣款 |
| 2026-10-10 | 六 | ❌ | 周末（调休上班但不开市） |
| 2026-10-15 | 四 | ✅ | 正常交易日 |
| 2026-10-17 / 18 | 六 / 日 | ❌ | 周末 |
| 2026-10-19 | 一 | ✅ | 注意：港股通因香港重阳节暂停，但 A 股正常开市 |

每交易日合计扣款 **¥25**（短债 5 + 沪深300 5 + 中证500 5 + 纳指100 10），**不设月终止金额**：一个月扣多少完全取决于当月交易日数。2026 年全年 242 个交易日，单月 14 天（2 月，春节）～23 天（7 月、12 月），对应约 **¥350～¥575/月**，月均约 ¥504。

## 七、每年维护

交易所通常在 **12 月下旬**发布下一年度休市安排。届时要：

1. 打开 `scripts/a_share_holidays.py`，在 `A_SHARE_HOLIDAY_RANGES` 中按 `年份: ((起, 止), ...)` 增加新年度区间。
2. 跑一次 `python tests/test_trading_day_rules.py`（或 `python -m unittest tests.test_trading_day_rules -v`）确认解析正常。
3. 若某年没有内置表、又拿不到 AKShare 日历，系统会**整天跳过并打警告**，不会误扣——日志里看到 `无 XXXX 年官方休市表` 就说明该补表了。

## 八、常见误区

| 误区 | 事实 |
|---|---|
| 「定投按自然日每天扣」 | 按**交易日**扣，周末与节假日不扣 |
| 「调休上班的周六会扣款」 | 不扣。交易所不开市就不是交易日（如 2026-10-10） |
| 「15:00 之后下单也算今天净值」 | 顺延到下一开放日 |
| 「QDII 按昨晚美股收盘价成交」 | 成交净值以基金合同估值日为准，可能晚于扣款日；不要写成「按昨晚美股收盘价成交」 |
| 「爬虫挂了就按工作日继续记账」 | 不会。日历不可用时跳过并告警（fail-closed） |
| 「没扣款 = 定投被取消了」 | 先看是不是非交易日顺延；再看公告的暂停申购 |
