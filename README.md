```powershell
# 用历史净值回填权益份额/持仓均价；券商对齐：--align 016452 61.23
python scripts/record_holding.py sell --fund 460300 --proceeds 90 --cost 80 --note "止盈1/3"
# 或按份额扣成本：--proceeds 90 --shares 10
# 幂等（北京时间 CST）：同日+同基金+同金额/份额+同备注 重复提交会被拒绝；备注不同=不同交易
# 可加 --tx-id；确需重复入账用 --force-duplicate
python scripts/send_trade_alert_email.py --dry-run --mode auto
# 强制监控周报 / 建仓事件：--mode force_dca | force_build
python app/ai_assistant.py --mode plan --input "本月可投入300元，510300估值分位32%"
```

买入/止盈后请把实际操作告诉助手（或自行 `record_holding.py`），README 持仓才会更新。  
四只标的的 `personal_schedules` 由交易日工作流自动补记，一般无需每天手动报；**`reconciled_through`（含）之前的日期不会再自动补记**，`effective_from` 之后的缺漏交易日才会补——避免补出无法核对的流水。持仓已在 2026-10-15 按招行 App 截图对账，份额重建步骤见 [上面的对账小节](#2026-10-15-截图对账一次性)。  
权益（沪深300/中证500/纳指）会按成交日净值估算份额并展示**相对持仓均价**；现价相对均价偏高时，建仓建议会软降级（每日自动定投不受影响）。以后手动买入请尽量带 `--shares` / `--nav`；也可 `--align` 用券商份额校准。  
手动定投补记请加 `--purpose dca`（或备注含「定投」）；建仓等不要标成 dca，以免扣错定投额度。  
同时给出 `--amount` 与 `--shares/--nav` 时，允许约 `max(0.02元, |金额|×0.5%)` 的差额，用于申购费、四舍五入和小额费用，并不要求账本金额与份额×净值完全一致。

定时刷新约 **工作日 12:00 CST**（GitHub cron 可能延迟或漏跑）。  
- **每交易日**：招行 App 自动扣款；工作流补记账本 + 监控「维持/建议暂停/加码」结论  
- **每周四（A股交易日）**：每日定投监控周报  
- **工作日**：监测档位/建仓；有实质性变更才发事件信  
- **A股休市**：不扣款（顺延下一交易日）；可刷美股 + 发动态事件信，不发周报  
- 工资日无单独邮件  
邮件含 `signal_date` / `order_date` / `cutoff_time`。若要手动调整定投，约 **13:00 CST** 前请到 Actions 确认 run 是否成功；run 失败不等于「今天没扣款」（扣款由银行执行）。

## 目录

- `config/portfolio_policy.json`：程序可读取的投资政策（含四只标的的每日定投 schedule）

- `config/mcp_servers.json`：MCP 服务和只读工具白名单

- `app/mcp_client.py`：MCP stdio 客户端

- `docs/TRADING_CALENDAR.md`：交易日规则说明

- `reports/`：AI 报告
- `data/`：行情和账户数据
- `integrations/upstream/`：只读上游项目副本
